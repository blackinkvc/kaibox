# 星轨开箱模拟器 (Stellar Crate Simulator)

单文件、离线可用的开箱模拟网页：演示"开箱 + 概率公示 + 保底 + 虚拟货币"这类玩法的交互与结算逻辑。纯前端，无后端、无账号、无网络请求。

## 如何打开

- 直接双击 `index.html`，用桌面浏览器（Chrome / Edge 等）打开即可，离线可用。
- 没有构建步骤，没有 npm 依赖。
- 存档保存在浏览器 `localStorage`（键名 `stellar_crate_sim_v1`），页面上的"重置存档"可清空。

## 箱子与概率

三个奖池，单价与传说基础概率：

| 箱子 | 单抽价格 | 传说基础概率 | 说明 |
| --- | --- | --- | --- |
| 星尘补给箱 | 100 星币 | 2% | 入门奖池，基础材料权重高 |
| 相位强化箱 | 300 星币 | 4% | 稀有、史诗权重提升 |
| 湮灭传说箱 | 800 星币 | 5% | 唯一可出"湮灭之瞳"的奖池 |

- 稀有度共 5 档：普通 / 精良 / 稀有 / 史诗 / 传说。
- 概率来源：物品权重硬编码在 `index.html` 的 `CRATES` 数据里，每个箱子权重合计 10000；页面"概率公示"页按稀有度汇总展示完整明细。
- 十连按 10 次单抽计价（价格 × 10），不额外打折。

## 保底规则

- **传说保底**：计数器跨全部箱子累计；累计第 90 抽仍无传说时，该抽强制为传说；抽到传说立即清零。
- **十连稀有保底**：每次十连至少产出 1 件稀有及以上；仅在一次十连内结算，单抽不触发，也不改变单抽概率。
- 保底会让长期综合出货率略高于公示的基础概率（传说档尤其明显），属于规则设计内的预期偏差。

## 虚拟充值声明

- 初始余额 3600 星币；充值档位只是示意（如 60 星币/示意 6 元，共 6 档）。
- 点击档位立即到账，全部为虚拟数字：不接入任何真实支付、不跳转支付页面、不产生真实交易，也没有任何货币价值。
- 概率与随机数全部由浏览器在本机生成（`Math.random`），不是任何真实游戏的掉落数据或线上接口返回。

## 验证方式与数据来源

- `verify/verify.js`：零依赖 Node 脚本，通过 CDP 驱动无头 Chrome，在 1600×900 下检查布局溢出、首屏可见性、余额、虚拟声明、保底规则、统计口径等，并截图到 `screenshots/`，结果写入 `verify/report-data.json`。
- `verify/mobile.js`：同样的方式做移动端设备模拟（375×667、390×844、414×896 等），检查横向溢出、首屏裁切、触控区域尺寸与性能，结果写入 `verify/mobile-report.json`，截图到 `screenshots/mobile/`。
- 两个脚本只用 Node 内置模块和 Chrome 远程调试端口，不引入第三方库。脚本里的 `ROOT` 与 `CHROME` 是作者本机的绝对路径，换机器运行前需要改成自己的路径。
- 仓库中的 report JSON 是一次验证运行的原始输出，可作为参考，不保证与最新 `index.html` 逐字节同步。
- 页面"统计"页展示的是本地实际出货率与公示基础率的对比，数据全部来自本机存档。

## 已知限制

- 无后端、无账号、无排行榜；清除浏览器数据即丢失存档。
- 开箱记录只保留最近 200 条（统计不受影响）。
- 所有文案、物品、价格、充值档位均为虚构演示内容。
